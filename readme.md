# Grokking Algorithms

A collection of Python implementations and notes based on **Grokking Algorithms** by Aditya Bhargava.

The purpose of this repository is to strengthen my understanding of fundamental algorithms and data structures by implementing each concept from scratch.

## Topics

- Binary Search
- Selection Sort
- Recursion
- Quicksort
- Hash Tables
- Breadth-First Search (BFS)
- Dijkstra's Algorithm
- Greedy Algorithms
- Dynamic Programming
- K-Nearest Neighbors (KNN)

## Goals

- Implement every algorithm covered in the book
- Write clean, readable Python code
- Include explanations and time complexity
- Build a solid DSA reference for interviews
